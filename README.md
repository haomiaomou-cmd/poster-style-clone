# poster-style-clone 海报风格克隆

一个 WorkBuddy 技能（Skill）：分析参考海报的风格要素，再用图像生成模型把指定主体图合成为**同风格的大字报式极简海报**（瑞士排版 × 杂志编辑风格）。

## 效果

上传 1-N 张参考海报 + 1 张主体图（产品/食物照片），技能会：

1. **区分素材**：自动识别参考海报 vs 主体图
2. **六维风格分析**：标题字体占比 / 图文层次 / 手写体点缀 / 配色方案 / 版式结构 / 整体气质，先输出中文分析再生成
3. **调用 ImageGen**：image1=主体图、image2=风格参照、1024x1536 竖版、内置英文 prompt 模板填空
4. **校验交付**：视觉核对主体/文字/层次/乱码，最多重试一次

## 沉淀的版式规则（经多轮迭代固化）

| 规则 | 说明 |
|------|------|
| 标题即主角 | 单词式超大压缩粗体撑满画面宽度 |
| 主体视觉中心 | 主体位于画面中央偏上，大幅遮挡大标题字母 |
| 花体异色叠压 | 手写体点缀与大标题异色（从主体取色），横穿覆盖字母中部 |
| 花体小巧 | 约为标题字高 1/3，只横跨中部 1/3 宽度，轻盈不喧宾夺主 |
| 标题+花体连读成梗 | 如 SUNNY / side up、HANGING / out to dry、STICKY / toffee pudding |
| 主体细节参与遮挡 | 滴落酱汁、丝带等延伸细节可流过字母表面，成为遮挡层次 |
| 无色块 | 不放任何 Pantone 式色卡装饰 |
| 右下角时间 | 右下角用时间表达（如 04:00 PM），不用日期 |
| 文案防乱码 | 左下角只用一句短句，prompt 显式要求拼写正确 |

## 实测案例

- 冰棒 → **COOL**（珊瑚橙底）
- 掉落甜筒 → **OOPS**（粉蓝底）
- 叉上轻食 → **STACKED**（砖红底）
- 奶油蛋糕 → **SWEET**（青蓝底）
- 苹果抽绳包 → **APPLE**（柔黄底）
- 太阳蛋 → **SUNNY** / side up（鲜橙底）
- 晾衣绳煎蛋 → **HANGING** / out to dry（蓝天底）
- 焦香吐司 → **TOAST** / well done（鲜橙底）
- 软糖葡萄串 → **GRAPE** / gummy bears（米白底）
- 薄纱礼物梨 → **PEAR** / for you（奶油米底）
- 太妃糖布丁 → **STICKY** / toffee pudding（奶油杏底）

## 安装

将整个 `poster-style-clone/` 目录放入 WorkBuddy 技能目录：

- 用户级：`~/.workbuddy/skills/poster-style-clone/`

## 使用

在 WorkBuddy 中提供几张参考海报和一张主体图，说「总结海报风格并生成同风格海报」即可触发。
