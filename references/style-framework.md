# 海报风格分析六维框架

对每张参考海报按以下维度分析，输出具体、可转化为生成 prompt 的结论。

## 1. 标题字体与占比

- 标题是单词还是短句？大写还是混合？
- 字体类型：粗壮无衬线（Helvetica/Arial Black 类）、装饰衬线（Didot/Playfair 类）、细长压缩体（condensed）？
- 占画面宽度比例：半幅 / 80%+ / 撑满并出血裁切？
- 标题在画面中的位置：顶部、中部、贯穿全图？
- 文字颜色：与背景同色系浅色调 / 对比色 / 描边空心？

示例结论：「TOMATO 一词用白色压缩型无衬线大写，占满画面宽度，位于画面中部，字母被主体照片部分遮挡。」

## 2. 图文层次关系

- 主体照片在文字之上（前层）还是之下（后层）？
- 是否有穿插：部分字母在前、部分在后？
- 照片是否跨越文字边界、破坏文字完整性以制造空间感？

示例结论：「橙子照片位于 COOL 文字之前，遮挡字母下半部，形成前后两层空间。」

## 3. 手写体 / 花体点缀

- 是否存在斜体手写、花体 script 叠加字？
- 内容是什么（人名、品类词、语气词）？位置（标题上方/穿过标题）？颜色？

示例结论：「白色花体 'summer' 一词叠加在 COOL 标题上方，形成笔刷感对比。」

## 4. 配色方案

- 背景色：具体描述（珊瑚橙、冰蓝、薄荷绿、砖红…）
- 背景与主体的关系：同色系呼应 / 互补撞色 / 中性衬托？
- 全图总色数：通常 2-3 色（背景色、文字色、主体本色）
- 是否有额外点缀色（色卡、分隔线）？

配法速查：
- 暖主体（橙、红、黄）→ 冷或中性背景（蓝、青、奶油白）
- 冷主体（蓝、紫）→ 暖背景（珊瑚橙、暖黄、砖红）
- 同色系时 → 靠明度差拉开层次

## 5. 版式结构与编辑元素

逐项检查是否存在并记录位置：
- 四角信息块：左上（品牌/栏目名）、右上（日期/期号）、左下（小段落文案）、右下（日期/编号）
- 细分隔线、星号、页码式编号（01/06）
- Pantone 式小色块
- 底部横向三词排布（FRESHER — LIGHTER — HAPPIER 式）
- 文案语言：英文 / 中文 / 双语混排

## 6. 整体气质

从以下词库选 2-3 个定位：
瑞士极简 Swiss Minimalism / 杂志编辑 Editorial / 复古印刷 Vintage Print / 现代电商 Modern Commerce / 俏皮手作 Playful / 高级感 Premium

## 分析输出格式

向用户输出时使用中文 markdown 列表，每个维度 1-2 行结论，最后附一句整体定位。分析完成后再进入生成环节。
